1. System Architecture

The platform consists of three isolated Docker containers orchestrated by Docker Compose. The Frontend communicates with the Backend via REST API calls.

Container 1

Frontend Service

Serves static HTML/JS/CSS files via Nginx.

  • - index_pink_october.html
  • - evaluation_dashboard.html
  • - signin.html
  • - Port: 8080
Container 2

Backend API

FastAPI server running Python ML inference.

  • - main.py (Router)
  • - ML Models (.pkl/.joblib)
  • - Data Schemas (Pydantic)
  • - Port: 8000

2. API Specification

The Backend team must implement these exact routes in FastAPI. The Frontend team will consume them using fetch().

Group A: Medical Interface (Doctor's View)

POST /api/v1/cellular/predict Single Prediction (WBCD)
// INPUT JSON {
  "radius_mean": 17.99,
  "texture_mean": 10.38,
  "perimeter_mean": 122.8,
  ... (all features)
}
// OUTPUT JSON {
  "diagnosis": "Malignant",
  "confidence": 0.98,
  "risk_tier": "High"
}
POST /api/v1/clinical/prognosis Prognosis & Forecast (METABRIC)
// INPUT JSON {
  "age": 55,
  "tumor_size": 25,
  "lymph_nodes": 4,
  ...
}
// OUTPUT JSON {
  "aggressiveness_score": 78,
  "growth_forecast": [25, 27, 30, 35, 42] // Array for Chart.js
}
POST /api/v1/cellular/batch CSV File Upload
Accepts multipart/form-data (CSV file). Returns a JSON list of predictions for the table.

Group B: Technical Interface (ML Engineer's View)

These endpoints power the Evaluation Dashboard charts.

GET /api/v1/evaluation/cellular/metrics Model Comparison Data
Returns performance data (Accuracy, AUC, F1, Recall) for all candidate models (RF, SVM, XGBoost) to populate the comparison table.
POST /api/v1/evaluation/cellular/shap Global SHAP Values
Returns the top feature names and their mean |SHAP| values for the Summary Plot bar chart.
GET /api/v1/evaluation/clinical/residuals Regression Error Plot
Returns X/Y coordinates of Actual vs. Predicted values to plot the Residual scatter chart for METABRIC model evaluation.

4. Docker Configuration

Create the following files in your project root to containerize the application.

/backend/Dockerfile

FROM python:3.9-slim

WORKDIR /app

# Install dependencies
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Copy app code
COPY ./app ./app

# Run FastAPI with Uvicorn
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]

/docker-compose.yml

version: '3.8'

services:
  # 1. The Brain (FastAPI)
  api:
    build: ./backend
    container_name: rosalytix_backend
    ports:
      - "8000:8000"
    volumes:
      - ./backend/app:/app/app  # Hot-reload
    environment:
      - ALLOW_ORIGINS=*

  # 2. The Face (Nginx Website)
  web:
    image: nginx:alpine
    container_name: rosalytix_frontend
    ports:
      - "8080:80"
    volumes:
      - ./frontend:/usr/share/nginx/html # Mount HTML files
    depends_on:
      - api

🚀 How to Launch

  1. Open terminal in project root.
  2. Run: docker-compose up --build
  3. Access Website: http://localhost:8080
  4. Access API Docs: http://localhost:8000/docs
