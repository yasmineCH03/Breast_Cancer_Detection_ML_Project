Core Technology Stack

Built with industry-standard tools for reliability and reproducibility.

DVC

Data Version Control. Tracks large datasets and model files alongside code, enabling reproducibility of any historical state.

MLflow

Experiment Tracking. Logs hyperparameters, metrics, and artifacts for every training run to compare performance.

GitHub Actions

CI/CD Automation. Automatically tests code, runs training jobs on commit, and packages artifacts.

FastAPI

Model Serving. High-performance API for real-time inference, serving the best model from the registry.

The Pipeline

End-to-End Workflow

1

Data Ingestion & Versioning

Raw data (WBCD dataset) is ingested and tracked using DVC. A .dvc file serves as a pointer to the actual data storage (S3, GDrive, or local).

dvc add data/row/data.csv git add data/row/data.csv.dvc git commit -m "Update dataset"
2

Training & Experimentation

The train_wbcd.py script runs the SGD-SVM model. MLflow automatically logs:

  • Hyperparameters (alpha, penalty)
  • Metrics (Accuracy, F1, AUC)
  • Serialized Model (.joblib)
3

CI/CD Pipeline

On every git push, GitHub Actions triggers:

Linting & Formatting (Black, Ruff)
Unit Tests (Pytest)
Model Training & Artifact Upload

Developer Quick Start

Run Training Locally

1. Install Dependencies

pip install -r Backend/requirements.txt

2. Run Training Script

python Backend/app/scripts/run_train_wbcd.py

3. View Experiments

mlflow ui

Data Operations

Initialize DVC

dvc init

Track New Data

dvc add Backend/app/data/row/data.csv git add Backend/app/data/row/data.csv.dvc .dvc/config git commit -m "Update dataset"
